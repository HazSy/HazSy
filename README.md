## Cómo trabajo

```text
1. Entender el problema y escribir los requisitos.
2. Diseñar el modelo de datos y la API antes de la interfaz.
3. Implementar por capas pequeñas, con commits que se puedan revisar.
4. Probar lo importante: casos límite, errores y seguridad.
5. Documentar las decisiones, no solo los comandos.
```
